# 波浪理论规则与经验比例（项目参考）

## 结构
- 推动浪：0-1-2-3-4-5（1、3、5 顺势；2、4 逆势）
- 调整浪：A-B-C（常见形态：锯齿 zigzag、平台 flat、三角形 triangle）
- 失败（截断）的第5浪：第5浪未越过第3浪顶就掉头，通常意味着动能衰竭。

## 铁律（违反即作废）
| 规则 | 说明 |
|---|---|
| R1 | 第2浪不能回撤超过第1浪起点（0点） |
| R2 | 第3浪不能是 1、3、5 中最短的一浪 |
| R3 | 第4浪不能进入第1浪的价格区间（楔形 ending/leading diagonal 除外） |

R3 的口径：`close` 用收盘价判断，`wick` 用盘中最高/最低价判断。

## 经验比例（用于打分，不是硬规则）
| 项目 | 常见范围 |
|---|---|
| 第2浪回撤第1浪 | 50%–61.8%（38.2%–78.6% 都常见） |
| 第3浪长度 | 1.618 × 第1浪（> 1.618 视为延长浪） |
| 第4浪回撤第3浪 | 23.6%–38.2%（超过 50% 偏深） |
| 第5浪长度 | 第3浪延长时 ≈ 1.0 × 第1浪；或 0.618 × 第1浪；或 0.382/0.618 × (0→3) |
| 交替原则 | 第2浪和第4浪形态/深度通常不同 |

## 第5浪目标（从第4浪终点出发）
- 0.618 × 第1浪
- 0.382 × (0→3 全长)
- 1.000 × 第1浪
- 0.618 × (0→3 全长)

## 见顶后的回撤目标（整轮 0→5 的回撤）
38.2%、50%、61.8%；第4浪区域通常是第一目标区。

## 动能确认
- 第3浪：MACD/RSI 通常最强。
- 第4浪：MACD 常回到零轴附近或下方。
- 第5浪：价格接近或创新高，但 MACD/RSI 峰值明显低于第3浪（背离或动能衰竭）。
- 确认信号：MACD 柱翻负（死叉）或价格跌破第5浪内部的小第4浪低点。

## 2026-10 原油案例（来自与 Claude 的讨论）
WTI 用户数浪：0=74，1=88.5，2=80.5，3=106，4=89.5。
- 第3浪约为第1浪 1.76 倍 → 延长浪 → 第5浪目标约 104（=第1浪长度）。
- 0.382×(0→3) ≈ 101.7，与 10/16 高点 101.91 吻合。
- 动能：第3浪 MACD 峰值约 5.3–5.6（视数据缺口处理），第5浪约 1.5–1.7 → 明显衰竭。
- 盘中口径下第4浪低点 86.90 < 第1浪顶 88.5 → 重叠，可能是楔形。
